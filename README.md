# Task 4: Advanced Analytics and Predictive Modeling

End-to-end statistical analysis, forecasting, customer segmentation, and predictive modeling on 2,500 synthetic retail transactions covering 2024-2025.

## Results

Run the notebook to generate the metric-filled results and artifacts below.

| Area | Deliverable |
| --- | --- |
| Statistics | Descriptive moments, Welch t-test, chi-square, ANOVA, 95% CIs |
| Forecasting | Weekly decomposition, ADF test, ARIMA 12-week forecast, MAE/RMSE/MAPE |
| Segmentation | RFM features, elbow and silhouette selection, K-Means personas, PCA |
| Prediction | Linear regression, logistic regression, decision tree, ROC-AUC |

## Project Layout

- `src/`: reusable typed pipeline modules
- `notebooks/`: executable analysis notebook
- `data/processed/`: generated transactions and customer segments
- `figures/`: publication-ready analysis plots
- `models/`: serialized models generated by the notebook

## Reproducible Run

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
jupyter notebook notebooks/Task_4_Advanced_Analytics_and_Modeling.ipynb
```

The notebook is the source of truth for the business narrative. All generated data is synthetic and intended for demonstration, not production decisions.

## Limitations

Synthetic data cannot establish causal relationships. Results are sensitive to the generated distributions, a single temporal split, model assumptions, and class balance. Validate with real customer-level history, leakage checks, calibrated probabilities, rolling time-series backtests, and business cost functions before deployment.
